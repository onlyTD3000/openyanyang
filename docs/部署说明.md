# 岩羊AI 平台 源码转让包

## 一、包内结构

| 目录 | 内容 |
|------|------|
| 网页端/网页端源码.zip | PHP 服务端 + 前端全部源码（含 vendor 依赖） |
| 客户端/客户端源码.zip | Electron 桌面客户端源码（不含 node_modules，需 npm install） |
| 安卓端/安卓端源码.zip | 安卓客户端源码（不含 gradle 缓存与签名密钥） |
| 数据库/8800demo_clean.sql | 干净数据库：45 张表结构 + 核心配置数据（脱敏版） |

## 二、数据库导入

```bash
# 1. 创建数据库（示例：8800demo）
CREATE DATABASE 8800demo DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
# 2. 导入
mysql -u<用户名> -p<密码> 8800demo < 8800demo_clean.sql
# 3. 创建同权限用户并授权（或用 root 导入后改配置）
```

## 四、部署后必须修改的项

1. **数据库连接**：`inc/config.php` 与 `inc/config.local.php` 中的 DB_NAME/DB_USER/DB_PASS
2. **渠道 API Key**：`channels` 表与 `api_platforms` 表的 api_key / access_token 已替换为占位符 `sk-demo-xxxx-REPLACE-ME`，需填入真实上游密钥
3. **站点地址**：`settings` 表 `site_url`（当前为 https://code.77bot.cn）
4. **支付配置**：`settings` 表 `alipay_private_key`、`alipay_public_key`、`alipay_app_id` 已清空，需重新配置支付宝开放平台
5. **邮件 SMTP**：`settings` 表 `email_smtp_*` 已清空
6. **Google 搜索**：`settings` 表 `google_api_key`、`google_cx` 已清空
7. **客户端/安卓端下载地址**：`settings` 表 `client_dl_*`、`android_dl_apk`、`dl_*` 指向原服务器，需替换为新服务器地址
8. **数据目录**：`inc/.data_dir.pin` 指向 `/www/wwwdata/8800`，部署新服务器后按需调整；主密钥文件（master.key）位于数据目录 secure/ 下，部署后自动生成，无需迁移

## 五、环境要求

- PHP 8.x（含 pdo_mysql、curl、mbstring、openssl、gd、dom、libxml、zip、fileinfo、opcache 扩展）
- MySQL 5.7+
- Nginx（需配置 WebSocket 反代 /ws/ 到 8801 端口）
- systemd 托管 wsssh_server.php（WebSocket SSH 终端）
- 可选：Python3（PPT 生成）、LibreOffice（Office 预览）、poppler-utils（PDF 预览）

## 六、已排除的敏感文件（不包含在包内）

- 服务端：`dec_pk.php`（解密工具）、`$包`（二进制）、`download/`、`downloads/`、`dl/`（安装包）、`backup/`（旧数据备份）、`.kiro_backup/`、`.sk_bak/`、全部 `.bak`/`.改前`/`_备份存档` 历史备份
- 客户端：`node_modules/`（459M，npm install 生成）、`dist/`、`build/`（含打包签名 key）
- 安卓端：`yanyang.jks`（签名密钥）、`keystore.properties`（签名密码）、`local.properties`（本机 SDK 路径）、`.gradle/`、`.kotlin/`

> 注意：客户端与安卓端源码均不含签名密钥。如需发布正式版，需自行生成新的签名密钥。
